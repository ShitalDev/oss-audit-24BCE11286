# OSS Audit Project

## Overview

This project explores open-source software concepts, Git, and how software operates within a Linux environment. It includes both theoretical analysis and practical implementation using Linux (WSL).

---

## Prerequisites

Before running this project, make sure you have:

* A Windows system with WSL installed **or** a Linux machine
* Git installed
* Internet connection

---

## Step 1: Install WSL (if using Windows)

Open PowerShell and run:

```
wsl --install
```

Restart your system after installation.

---

## Step 2: Install Git on Linux

Open your Linux terminal and run:

```
sudo apt update
sudo apt install git
```

Verify installation:

```
git --version
```

---

## Step 3: Clone the Repository

Clone this project from GitHub:

```
git clone https://github.com/your-username/oss-audit-24BCE11286.git
```

Navigate into the project folder:

```
cd oss-audit-24BCE11286
```
